# ЮВИ — сайт студии разработки

Статический сайт-визитка. Ни сборки, ни зависимостей, ни `npm install`.

## Как открыть

Просто откройте `index.html` двойным кликом.

Если хотите как на боевом сервере (нужно для корректных путей и шрифтов):

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Открывающая сцена: робот смахивает непрогрузившуюся страницу

Посетитель попадает на страницу, которая как будто не загрузилась: битые
значки картинок, серые полоски вместо текста, синие полоски вместо ссылок.
Через полторы секунды слева направо проезжает робот и смахивает этот слой —
под ним уже готовый сайт, с которым можно работать.

Сам слой лежит **на верхнем уровне документа, а не внутри `main`**: у `main`
свой контекст наложения, и оттуда перекрытие не смогло бы закрыть шапку —
получались бы две шапки сразу.

Движение делает CSS, скрипт только переключает состояния. Тайминги — в
`:root` в начале `style.css`:

| Переменная | Смысл | По умолчанию |
|---|---|---|
| `--sweep-delay` | сколько «битая» страница висит до взмаха | `1.6s` |
| `--sweep-ms` | сколько длится сам взмах | `1.5s` |

Уборка сцены запускается тремя независимыми способами, чтобы посетитель ни
при каких обстоятельствах не застрял перед битой страницей:

1. штатно — по окончании анимации смахивания;
2. по таймеру-страховке, если событие окончания почему-то не пришло;
3. по любому действию посетителя — клик, клавиша, колесо, касание.

Плюс сцены нет вовсе, если отключён JS или в системе стоит
`prefers-reduced-motion`: тогда сразу виден настоящий сайт.

## Реактивный фон

`<canvas>` на всю страницу рисует сетку квадратов. Рядом с курсором они растут,
поворачиваются к нему и синеют, под курсором добавляется мягкое свечение. Кадры
считаются только пока картинка не успокоилась, поэтому в простое нагрузки нет.
Код — блок 7 в `assets/js/main.js`.

## Остальной интерактив

| Что | Где в коде |
|---|---|
| Шкала разделов слева (появляется от 1400 px) | блок 7d, `.rail` |
| Фильтр работ по нише | блок 7b, `.filter` + `data-cat` на карточке |
| Парящие фигуры в первом экране, параллакс за курсором | блок 7c, `.figure` |
| Линия над этапами, заполняется по мере скролла | блок 7d, `--fill` на `.steps` |
| Появление блоков при скролле | блок 8, прямая проверка позиции без `IntersectionObserver` |

## Обложки работ

Шесть обложек в `assets/img/` — это нарисованные с нуля макеты сайтов, а не
абстрактные заглушки. По две на нишу:

| Файл | Что показывает | Ниша |
|---|---|---|
| `cover-build-01.svg` | сайт генподрядчика | строительство |
| `cover-build-02.svg` | сайт жилого комплекса | строительство |
| `cover-edu-01.svg` | платформа учебного центра | образование |
| `cover-edu-02.svg` | сайт школы | образование |
| `cover-med-01.svg` | сайт стоматологической клиники | стоматология |
| `cover-med-02.svg` | онлайн-запись сети клиник | стоматология |

Названий компаний в обложках нет намеренно: в месте логотипа стоит категория
(«ГЕНПОДРЯДЧИК», «ШКОЛА», «СЕТЬ КЛИНИК»), чтобы случайно не совпасть с настоящей
организацией. По той же причине карточки названы по типу проекта, а не по бренду,
а врач в виджете записи подписан «Фамилия И. О.».

Палитры разведены так, чтобы никакие две обложки не читались одинаково:

| Ниша | Палитра |
|---|---|
| генподряд | графит `#17191C` + сигнальный оранжевый `#FF6A1F` |
| застройщик | бетон `#EFEDE7` + тёмно-зелёный `#1F4B3F` |
| учебный центр | белый + фиолетовый `#6D28D9` + лайм `#C8F135` |
| школа | кремовый `#FDF8EE` + янтарный `#B45309` |
| клиника | тёмный тил `#0C3A3B` + аква `#2DD4BF` |
| сеть клиник | светлая роза `#FFF5F7` + глубокая роза `#BE185D` |

Когда появятся реальные проекты, замените файл на скриншот (`.jpg`/`.webp`),
поправив `src`, `width` и `height` в карточке. Ниша карточки задаётся атрибутом
`data-cat` — `build`, `edu` или `med`; если
добавляете новую, не забудьте кнопку в `.filters` и счётчик в ней.

## Языки

Переключатель `RU / EN` в шапке. Никаких библиотек: у каждого текстового узла есть
атрибуты `data-ru` и `data-en`, скрипт подставляет нужный и запоминает выбор в
`localStorage`.

Чтобы добавить новый текст на двух языках:

```html
<p data-ru="Текст по-русски" data-en="Text in English">Текст по-русски</p>
```

Содержимое тега должно совпадать с `data-ru` — это то, что видит посетитель до
запуска скрипта.

## Что заменить на своё

Все места помечены в коде комментарием `TODO`. Найти их разом:

```bash
grep -rn "TODO" index.html
```

Список:

1. **Контакты** — секция `#contact` в `index.html`. Телефона и почты там нет
   намеренно: остались Telegram `@yuvi_web` и Instagram `@yuvi.web`, оба реальные.
   Появится почта на своём домене — добавьте третьей карточкой и верните
   `email` в блок JSON-LD внизу файла.
2. **Сроки** — шесть карточек в секции `#services`. Цен на сайте нет намеренно:
   вместо суммы у каждой услуги стоит срок, а смета считается под задачу.
3. **Условия в первом экране** — блок `.terms`: три обещания клиенту. Цифр
   «проектов / лет на рынке» там намеренно нет — новой студии их брать неоткуда,
   а обещания можно выполнить с первого заказа.
4. **Кейсы** — секция `#work` и обложки `assets/img/cover-*.svg`. Названия,
   описания, сроки и годы вымышленные — замените на свои проекты.
5. **Домен** — `og:image` и ссылки, когда купите домен.

## Логотип

Робот воссоздан в SVG по вашим картинкам — исходники лежат в
`reference/robot-open-eyes.jpg` и `reference/robot-closed-eyes.jpg`:

- `assets/img/robot-mark.svg` — знак-голова для шапки, подвала и OG;
- `assets/img/favicon.svg` — иконка вкладки;
- полная фигура лежит инлайном в `index.html` внутри `.crafted__robot` — так
  скрипт может водить глазами за курсором и моргать, а корпус плавно парит.

Почему SVG, а не сами JPG: растр не даёт ни слежения за курсором, ни моргания,
у него непрозрачный фон (на белой странице была бы видна серая подложка),
и он не масштабируется. Вторая картинка с прищуренными глазами пригодилась
как кадр моргания — при моргании открытые глаза подменяются на неё.

Если появится оригинальный файл логотипа, положите его в `assets/img/` и замените
ссылки; инлайновую фигуру можно заменить целиком.

## Структура

```
index.html              вся страница
assets/css/style.css    дизайн-система и вёрстка
assets/js/main.js       язык, меню, ревеал, фон, робот, скролл
assets/img/             логотип, фавикон, обложки работ
bot/                    телеграм-бот студии, свой README внутри
social/                 аватары и посты для Instagram
reference/              ваши референсы, на сайт не попадают
```

## Шрифты

`Unbounded` (заголовки), `Inter` (текст), `JetBrains Mono` (цифры и лейблы) —
все с кириллицей, подключены с Google Fonts. Если сайт должен работать без
интернета, скачайте `.woff2` в `assets/fonts/` и замените `<link>` на `@font-face`.

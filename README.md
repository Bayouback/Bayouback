# ЮВИ — сайт студии разработки

Статический сайт-визитка. Ни сборки, ни зависимостей, ни `npm install`.

## Как открыть

Просто откройте `index.html` двойным кликом.

Если хотите как на боевом сервере (нужно для корректных путей и шрифтов):

```bash
python3 -m http.server 8000
# затем http://localhost:8000
```

## Главный приём: «починка сайта курсором»

Первый экран стартует как нарочно скучный сайт из 2000-х: Times New Roman, серые
таблицы, синие подчёркнутые ссылки, счётчик посещений. Под курсором проступает
настоящий дизайн — круглое окно в слой с роботом и типографикой.

Чем больше пути прошла мышь, тем шире окно. После ~3400 пикселей движения дизайн
раскрывается целиком и остаётся. Это буквальная демонстрация услуги: вот что мы
делаем со скучными сайтами.

Настройки — в начале блока 5 в `assets/js/main.js`:

| Константа | Смысл | По умолчанию |
|---|---|---|
| `TARGET` | сколько пикселей движения мыши до полного раскрытия | `3400` |
| `R_MIN` | стартовый радиус окна | `140` |
| `R_MAX` | радиус перед раскрытием | `300` |
| `IDLE_MS` | если мышь стоит — раскрыть само | `6000` |

Приём аккуратно вырождается, когда не работает:

- **нет JS** — настоящий дизайн виден сразу, маску ставит только скрипт;
- **тач-устройство** — курсора нет, поэтому раскрытие по первому касанию или через 2.2 с;
- **`prefers-reduced-motion`** — маска и подсказка выключены целиком;
- **клавиатура** — фокус внутри первого экрана раскрывает дизайн, плюс есть кнопка
  «Показать сразу»;
- **скролл ниже первого экрана** — тоже раскрывает.

Скучный слой помечен `aria-hidden="true"`: скринридеры и поисковики читают только
настоящий контент.

## Реактивный фон

`<canvas>` на всю страницу рисует сетку квадратов. Рядом с курсором они растут,
поворачиваются к нему и синеют, под курсором добавляется мягкое свечение. Кадры
считаются только пока картинка не успокоилась, поэтому в простое нагрузки нет.
Код — блок 7 в `assets/js/main.js`.

## Остальной интерактив

| Что | Где в коде |
|---|---|
| Шкала разделов слева (появляется от 1400 px) | блок 7d, `.rail` |
| Фильтр работ по нише | блок 7b, `.filter` + `data-cat` на карточке |
| Парящие фигуры в первом экране, параллакс за курсором | блок 7c, `.figure` |
| Линия над этапами, заполняется по мере скролла | блок 7d, `--fill` на `.steps` |
| Появление блоков при скролле | блок 8, прямая проверка позиции без `IntersectionObserver` |

## Обложки работ

Шесть обложек в `assets/img/` — это нарисованные с нуля макеты сайтов, а не
абстрактные заглушки. По две на нишу:

| Файл | Проект | Ниша |
|---|---|---|
| `cover-monolit.svg` | Монолит-Строй | строительство, генподряд |
| `cover-granit.svg` | Гранит Девелопмент | строительство, застройщик |
| `cover-vektor.svg` | Вектор | образование, учебный центр |
| `cover-licey.svg` | Лицей №14 | образование, школа |
| `cover-dental.svg` | Дентал Про | стоматология, клиника |
| `cover-klyuch.svg` | Белый Ключ | стоматология, сеть |

У каждой своя палитра под нишу: оранжевый и графит для стройки, индиго и жёлтый
для учёбы, мятный для стоматологии. Когда появятся реальные проекты, замените
файл на скриншот (`.jpg`/`.webp`), поправив `src`, `width` и `height` в карточке.
Ниша карточки задаётся атрибутом `data-cat` — `build`, `edu` или `med`; если
добавляете новую, не забудьте кнопку в `.filters` и счётчик в ней.

## Языки

Переключатель `RU / EN` в шапке. Никаких библиотек: у каждого текстового узла есть
атрибуты `data-ru` и `data-en`, скрипт подставляет нужный и запоминает выбор в
`localStorage`.

Чтобы добавить новый текст на двух языках:

```html
<p data-ru="Текст по-русски" data-en="Text in English">Текст по-русски</p>
```

Содержимое тега должно совпадать с `data-ru` — это то, что видит посетитель до
запуска скрипта.

## Что заменить на своё

Все места помечены в коде комментарием `TODO`. Найти их разом:

```bash
grep -rn "TODO" index.html
```

Список:

1. **Контакты** — секция `#contact` в `index.html`: почта, Telegram, телефон.
   Продублированы в блоке JSON-LD внизу файла.
2. **Цены** — карточки в секции `#services`.
3. **Цифры в первом экране** — блок `.stats`: проектов, лет, средний срок.
4. **Кейсы** — секция `#work` и обложки `assets/img/cover-*.svg`. Названия,
   описания, сроки и годы вымышленные — замените на свои проекты.
5. **Домен** — `og:image` и ссылки, когда купите домен.

## Логотип

Робот воссоздан геометрией в SVG по вашему референсу:

- `assets/img/robot-mark.svg` — знак-голова для шапки, подвала и OG;
- `assets/img/favicon.svg` — иконка вкладки;
- полная фигура робота лежит инлайном в `index.html` внутри `.crafted__robot` —
  так скрипт может двигать зрачки за курсором и моргать.

Если появится оригинальный файл логотипа, положите его в `assets/img/` и замените
ссылки; инлайновую фигуру можно заменить целиком.

## Структура

```
index.html              вся страница
assets/css/style.css    дизайн-система и вёрстка
assets/js/main.js       язык, меню, ревеал, фон, робот, скролл
assets/img/             логотип, фавикон, обложки работ
reference/              ваши референсы, на сайт не попадают
```

## Шрифты

`Unbounded` (заголовки), `Inter` (текст), `JetBrains Mono` (цифры и лейблы) —
все с кириллицей, подключены с Google Fonts. Если сайт должен работать без
интернета, скачайте `.woff2` в `assets/fonts/` и замените `<link>` на `@font-face`.

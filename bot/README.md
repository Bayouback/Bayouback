# Телеграм-бот ЮВИ

Бот отвечает клиентам на частые вопросы сам, а когда вопрос выходит за рамки
сценария — собирает заявку и передаёт её вам. Это ровно та схема, которую студия
продаёт клиентам, только про себя: можно показывать как живой пример.

---

## Что он умеет

**Отвечает на вопросы своими словами клиента.** Человеку не обязательно жать
кнопки: он пишет «а сколько будет стоить магазин» — бот понимает, что вопрос про
деньги, и отвечает. Распознаёт темы: услуги, сроки, цена, условия работы,
процесс, ниши и кейсы, чат-боты, контакты, приветствие и благодарность.

**Показывает меню.** Под каждым ответом семь кнопок — чтобы человек, который не
знает, что спросить, всё равно куда-то нажал.

**Собирает заявку.** Три вопроса: имя, задача, куда ответить. Готовая заявка
приходит вам в личку.

**Не заходит в тупик.** Если бот не понял вопрос, он честно это говорит,
предлагает меню и оставить заявку — а не молчит и не повторяет одно и то же.

## Запуск за десять минут

### 1. Создайте бота в Telegram

Откройте [@BotFather](https://t.me/BotFather) и отправьте `/newbot`. Он спросит
две вещи:

- **имя** — видно в шапке чата, можно по-русски: `ЮВИ — сайты и чат-боты`
- **username** — адрес бота, только латиница, обязан кончаться на `bot`:
  например `yuvi_web_bot`

В ответ придёт строка вида `8123456789:AAHdqAbc...` — это **токен**. Он даёт
полный доступ к боту: не выкладывайте его в чаты, не коммитьте в репозиторий.
Если засветили — `/revoke` у BotFather, и токен сменится.

### 2. Поставьте Python и библиотеку

Нужен Python 3.10 или новее. Проверить: `python3 --version`.

```bash
cd bot
python3 -m venv .venv          # отдельное окружение, чтобы не сорить в системе
source .venv/bin/activate      # в Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

### 3. Запустите

```bash
export BOT_TOKEN="сюда ваш токен"
python3 bot.py
```

В Windows через PowerShell вместо `export` пишут:

```powershell
$env:BOT_TOKEN = "сюда ваш токен"
python bot.py
```

В консоли появится `Бот запускается`. Откройте своего бота в Telegram, нажмите
«Запустить» — он ответит приветствием. Остановить — `Ctrl+C`.

### 4. Настройте приём заявок

Пока вы не указали, куда слать заявки, они пишутся только в консоль. Чтобы
приходили в личку:

1. напишите [@userinfobot](https://t.me/userinfobot) — он ответит вашим числовым ID;
2. **напишите своему боту хоть что-нибудь** — Telegram не разрешает ботам писать
   первыми, пока вы не начали диалог;
3. запустите с этим ID:

```bash
export ADMIN_CHAT_ID="ваш числовой id"
python3 bot.py
```

Удобнее один раз положить оба значения в файл `.env` (скопируйте `.env.example`)
и подгружать их: `set -a && source .env && set +a && python3 bot.py`.

## Как менять тексты

Все ответы лежат в **`content.py`** — там нет ни строчки логики, только текст.
Поменяли, перезапустили бота, готово.

Добавить услугу — допишите строку в список `SERVICES`, она сама попадёт и в ответ
про услуги, и в ответ про сроки:

```python
SERVICES = [
    ("Лендинг", "одна страница под одну задачу", "2 недели"),
    ("Приложение", "личный кабинет для клиентов", "12–16 недель"),   # новая
]
```

Добавить кнопку — впишите её в `MENU` и добавьте текст в `ANSWERS` под тем же
кодом. Если забудете текст, это поймают тесты (ниже).

> **Держите бота и сайт в одном месте.** Сроки, условия и контакты в `content.py`
> повторяют то, что написано на сайте. Поменяете на сайте — поменяйте и здесь:
> расхождение между сайтом и ботом клиенты замечают быстро.

## Как научить понимать новые вопросы

Ключевые слова — в **`router.py`**, список `INTENTS`. Правила два:

- ключ **с пробелом** ищется как целая фраза: `"сколько стоит"`;
- ключ **без пробела** считается началом слова: `"срок"` поймает «сроки»,
  «сроках», «срочно», но не «сросся».

Второе сделано не для красоты. Если искать просто подстроку, ключ `"бот"` найдётся
внутри слова «ра**бот**а», и вопрос «как построена работа» уедет в ответ про
чат-ботов. Сравнение по началу слова это исключает.

**Порядок в списке важен** — побеждает первое совпадение, поэтому узкие темы стоят
выше широких. Ключ `"сайт"` лежит в самом низу: иначе он перехватывал бы и «сколько
стоит сайт», и «хочу заказать сайт».

После правок обязательно прогоните тесты:

```bash
python3 test_router.py
```

Токен и интернет для этого не нужны. Тесты проверяют 43 живые фразы, ловят
перехват чужих тем и следят, чтобы у каждой кнопки был текст ответа. Добавляете
ключевое слово — допишите туда пару примеров.

## Чтобы бот работал всегда

Пока запущен `python3 bot.py` на вашем компьютере — бот отвечает. Закрыли ноутбук,
он замолчал. Для боевой работы нужен сервер, который не выключается.

Самый простой путь — дешёвый VPS (200–400 ₽ в месяц) и `systemd`, чтобы бот
поднимался сам после перезагрузки. Файл `/etc/systemd/system/yuvi-bot.service`:

```ini
[Unit]
Description=YUVI Telegram bot
After=network.target

[Service]
WorkingDirectory=/opt/yuvi-bot
Environment=BOT_TOKEN=ваш_токен
Environment=ADMIN_CHAT_ID=ваш_id
ExecStart=/opt/yuvi-bot/.venv/bin/python bot.py
Restart=always

[Install]
WantedBy=multi-user.target
```

Дальше `systemctl enable --now yuvi-bot`, смотреть логи — `journalctl -u yuvi-bot -f`.

## Что можно добавить дальше

**Понимание свободных формулировок.** Сейчас бот работает по ключевым словам: это
бесплатно, предсказуемо и никогда не выдумывает фактов. Минус — совсем неожиданную
формулировку он не поймёт и отправит в меню. Если нужно понимать что угодно, поверх
ставится языковая модель: она разбирает вопрос, а отвечает всё равно по вашим
текстам, чтобы не сочинять цены и сроки. Это уже платно, по количеству запросов.

**Запись в календарь.** Для клиентских ботов мы делаем показ свободных окон и
запись — как в кейсе для сети клиник. Здесь этого нет, потому что студии
записывать нечего.

**Хранение заявок.** Сейчас заявка уходит вам в личку и пишется в лог. Если
заявок станет много — их складывают в таблицу или CRM.

# Посты для Instagram

Двенадцать готовых картинок 1080×1080, PNG. Порядок публикации — по номеру в имени файла.

| Файл | Пост | Тип |
|---|---|---|
| `01-znakomstvo.png` | Делаем сайты и ботов | визитка, закрепить в профиле |
| `02-do-posle.png` | Было / Стало | приём, до и после |
| `03-keys-stroyka.png` | Сайт генподрядчика | кейс |
| `04-chat-boty.png` | Отвечает в 3 часа ночи | услуга, чат-боты |
| `05-tseny.png` | Честный прайс | цены |
| `06-5-oshibok.png` | 5 ошибок на сайте клиники | польза, обложка карусели |
| `07-keys-ucheba.png` | Платформа учебного центра | кейс |
| `08-bot-ili-forma.png` | Бот или форма | сравнение |
| `09-process.png` | Пять шагов до запуска | процесс |
| `10-keys-bot-zapisi.png` | Бот записи для сети клиник | кейс, боты |
| `11-usloviya.png` | Фикс-смета, правки, исходники | условия |
| `12-prizyv.png` | Расскажите про задачу | призыв к действию |

Тексты подписей к каждому посту — на странице-раскладке, ссылку на неё дал в переписке.

Картинки собраны из HTML и отрисованы в браузере, поэтому текст в них можно
поменять и перерисовать заново, а не переделывать в графическом редакторе.
Исходник раскладки — `build_insta.py` в рабочих файлах сессии; если понадобится
править, попросите — пересоберу.

Шрифты в макетах: Unbounded (заголовки), Inter (текст), JetBrains Mono (лейблы).

# Иконки профиля

Робот тот же, что на сайте. Два фона, два размера.

| Файл | Куда | Размер |
|---|---|---|
| `ig-avatar-dark.png` | Instagram, **по умолчанию** | 1080×1080 |
| `ig-avatar-light.png` | Instagram, светлый вариант | 1080×1080 |
| `tg-avatar-dark.png` | Telegram — аккаунт и бот, **по умолчанию** | 512×512 |
| `tg-avatar-light.png` | Telegram, светлый вариант | 512×512 |

**Берите тёмный.** Интерфейс обеих сетей белый, и на 32 px в ленте и в списке
чатов тёмный кружок читается, а светлый почти сливается с фоном — это видно,
если сравнить последние две колонки на контрольном листе.

Композиция собрана под круглую обрезку: голова, ушки и антенна помещаются в
окружность, вписанную в квадрат, с запасом по краям.

`avatar-light.svg` и `avatar-dark.svg` — исходники. У них намеренно нет
фиксированных `width`/`height`: иначе при рендере в размер меньше исходного
в кадр попадает только угол. Растягиваются по вьюпорту, поэтому из них
выводится любой размер.

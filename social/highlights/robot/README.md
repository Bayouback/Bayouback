# Обложки «актуального» с роботом

Восемь вариантов 1080×1920. Первые четыре — только аватарка на разном фоне,
остальные добавляют к ней что-то ещё.

| Файл | Что это |
|---|---|
| `01-belyy.png` | робот на белом |
| `02-grafit.png` | робот на графите `#0B0B0C` |
| `03-siniy.png` | робот на фирменном синем `#3E8BFF` |
| `04-bezhevyy.png` | робот на бежевом `#F4EEE4` |
| `05-disk.png` | синий диск под роботом на белом |
| `06-golova.png` | крупный кроп головы — заполняет кружок целиком |
| `07-geometriya.png` | робот поверх фирменной геометрии: квадрат, круг, засечки |
| `08-znak.png` | плоский знак с сайта вместо объёмного робота |

## Что выбрать

**`06-golova`** — если нужен один вариант. В профиле кружок показывается
размером примерно 72 px, и на этом размере выигрывает тот, у кого крупнее
деталь: голова заполняет круг целиком и узнаётся сразу.

**`05-disk`** и **`02-grafit`** — если кружки должны выделяться в ряду:
цветное пятно и тёмное пятно заметны даже боковым зрением.

**`01-belyy`** — если профиль должен оставаться светлым и спокойным. В ряду
белых кружков на белом фоне граница почти не читается, зато выглядит тихо.

Один и тот же файл можно поставить на все шесть кружков: различать их будут
названия, которые Instagram подписывает снизу. Если хотите, чтобы кружки
отличались и картинкой — берите соседние варианты из этого набора либо
значковые обложки уровнем выше (`../hl-*.png`).

## Почему робот такой крупный

Первый заход был собран «красиво в кадре»: робот занимал половину картинки
1080×1920. В кружке 72 px от него оставалось пятнышко. Поэтому робот
увеличен почти до границ круга — при ширине картинки 1120 он занимает
673×791 из круга диаметром 1080 и в него всё ещё вписывается по углам.

Проверять такие обложки нужно на настоящем размере, а не на крупном превью:
на превью читаемо всё.

## Как пересобрать

```bash
pip install pillow numpy scipy      # если ещё не стоят
python3 build_covers.py куда-положить
```

Скрипт берёт вырезанного робота из `../../robot/robot-open.png` и знак из
`../../../assets/img/robot-mark.svg`, так что менять их отдельно в обложках
не нужно — достаточно пересобрать.

Всё важное держится внутри круга диаметром 900 с центром в точке (540, 960):
именно оттуда Instagram вырезает кружок.

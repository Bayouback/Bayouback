# Референсы

Сюда кладите картинки и скриншоты, на которые я должен ориентироваться:
логотип-робот, примеры сайтов, палитры, шрифты, макеты.

Подойдут `.png`, `.jpg`, `.webp`, `.svg`, `.pdf`.

Полезно давать файлам говорящие имена, например:
`robot-icon.png`, `ref-huyml-hero.png`, `ref-gionatannese-grid.png`.

Файлы из этой папки используются только как ориентир при разработке
и на готовый сайт не попадают — рабочие ассеты лежат в `assets/img/`.
